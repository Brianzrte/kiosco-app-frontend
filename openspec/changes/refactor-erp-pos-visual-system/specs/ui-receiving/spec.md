## ADDED Requirements

### Requirement: Receiving workspace hierarchy

Receiving list, detail and confirmation dialogs SHALL use the shared
administrative workspace hierarchy while keeping pending/received status,
supplier, date, total and receiving action prominent. Pending and received
states SHALL remain labelled in addition to any visual accent.

#### Scenario: Receiving operator distinguishes the next action
- **WHEN** an authorized user opens a purchase order
- **THEN** they can determine whether it is pending or received and whether a
  receiving action is available without relying on colour alone
