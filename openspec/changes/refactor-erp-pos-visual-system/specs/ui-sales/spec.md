## ADDED Requirements

### Requirement: Sales workspace hierarchy

Sales history, sale detail and return history SHALL use the shared
administrative workspace hierarchy while preserving sale number, status,
payment information, totals and return actions as the dominant records. A
payment method or return state SHALL retain text and icon/badge reinforcement
when colour is used.

#### Scenario: Sales record remains comparable
- **WHEN** an authorized user views sales history or a sale detail
- **THEN** they can identify the record's status, payment information and total
from the refactored layout without interpreting colour alone
